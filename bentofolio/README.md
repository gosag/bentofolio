# Bentofolio

A sleek, responsive bento-box style personal portfolio. Built with React, TypeScript, and Vite.

## Features

- **Bento Box Layout:** Clean and modern grid-based design.
- **Interactive Spotlight Effect:** Mouse-tracking spotlight effect for enhanced visual engagement.
- **Framer Motion Animations:** Smooth entrance animations.
- **GitHub Contributions** Displays your GitHub activity directly in your portfolio.
- **Responsive Design:** Optimized for mobile, tablet, and desktop views.
- **Dark Mode Support:** (Configurable) Tailored for dark themes.
- **Tech Stack:** React 19, TypeScript, Tailwind CSS, Vite, Framer Motion, and shadcn-ui.

## Installation and Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/gosag/bentofolio.git
    cd bentofolio
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    ```

4.  **Open your browser:**
    Navigate to `http://localhost:5173`.

## Scripts

-   `npm run dev`: Starts the Vite development server.
-   `npm run build`: Builds the project for production.
-   `npm run lint`: Runs ESLint to check for code issues.
-   `npm run preview`: Previews the production build locally.
