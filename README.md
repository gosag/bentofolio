# Bentofolio 🍱

A modern, dark-themed personal portfolio built with a **bento grid** layout — every skill, project, and stat gets its own card, so visitors get the full picture at a glance instead of scrolling through endless sections.

**Live demo:** [gosagirma.me](https://gosagirma.me)

## 🏗️ Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/gosag/bentofolio.git
cd bentofolio
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
